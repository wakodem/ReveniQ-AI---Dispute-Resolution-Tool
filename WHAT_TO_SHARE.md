# What to share with your colleague – ReveniQ AI

**Share this folder:** `ReveniQ-AI` (the whole project folder).

---

## Include (required for the app to run)

| Item | Purpose |
|------|--------|
| **dashboard.py** | Streamlit dashboard entry point |
| **requirements.txt** | Python dependencies (pandas, streamlit) |
| **reveniq_ai/** | Python package (all `.py` files inside) |
| **run_dashboard.ps1** | Script to start the dashboard (optional) |
| **INITIAL_GOAL_STEPS.md** | Step-by-step setup and run guide |

## Include (data – optional)

| Item | Purpose |
|------|--------|
| **dispute_categorisation_60days.csv** | Sample data; include if you want them to run with the same dataset. If they have their own CSV, they can omit this and put their file in the same folder. |

## Exclude (do not share)

| Item | Why |
|------|-----|
| **reveniq_ai/__pycache__/** | Generated bytecode; recreated on their machine |
| **reveniq_ai/connectors/__pycache__/** | Same |
| **reveniq_ai/models/__pycache__/** | Same |
| **.venv/** or **venv/** | Virtual environment; colleague creates their own |
| **.streamlit/** (if any secrets) | Local Streamlit config |

---

## How to share

1. **Option A – Zip**
   - Copy the `ReveniQ-AI` folder.
   - Delete all `__pycache__` folders (and `.venv` if present) from the copy.
   - Zip the folder and share the zip (e.g. email, Teams, OneDrive).

2. **Option B – Git**
   - If you use Git, add a `.gitignore` with `__pycache__/`, `.venv/`, `venv/`, `*.pyc`.
   - Push the repo and share the link; colleague clones it.

---

## What your colleague does after receiving

1. Unzip (or clone) into a folder, e.g. `C:\Users\<name>\ReveniQ-AI`.
2. Open PowerShell in that folder: `cd C:\Users\<name>\ReveniQ-AI`.
3. Create venv (optional): `python -m venv .venv` then `.\.venv\Scripts\Activate.ps1`.
4. Install deps: `pip install -r requirements.txt`.
5. Run dashboard: `streamlit run dashboard.py`.
6. See **INITIAL_GOAL_STEPS.md** for full steps and CSV path/columns.
